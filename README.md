💰 Expense Tracker – Frontend

Track Smart. Spend Wisely.

A modern and user-friendly Expense Tracker web application that helps users manage their income and expenses, monitor their balance, and understand their spending habits through interactive charts and reports.

Built as a real-world project under Code Classroom AI.

🌟 Features

- 💵 Income Tracking – Manage your income transactions.
- 💸 Expense Tracking – Record and manage daily expenses.
- 📊 Balance Overview – View your income, expenses, and available balance.
- 📈 Interactive Charts – Visualize financial data using Chart.js.
- 📅 Monthly Reports – Understand monthly spending patterns.
- ➕ Add Transactions – Add new income and expense records.
- 🗑️ Delete Transactions – Remove transactions when needed.
- 🔍 Search & Filter – Find transactions by keyword, type, or category.
- 🔗 Backend Integration – Connect with a FastAPI REST API.

🛠️ Technologies Used

Technology| Purpose
HTML5| Webpage structure
CSS3| Styling and responsive design
JavaScript| Application functionality
Chart.js| Interactive charts
Python| Backend development
FastAPI| REST API integration
SQLite| Database storage

🏗️ Project Architecture

Frontend → FastAPI REST API → SQLite Database

The frontend communicates with the backend to retrieve, create, and delete transaction records.
